# Dra. Renata Fortunato

Landing page responsiva em HTML, CSS e JavaScript, com imagens WebP e fontes locais.

## Executar

Abra `index.html` no navegador ou sirva esta pasta em qualquer servidor estático. Não é necessário compilar.

## Publicação

GitHub Pages: branch `main`, pasta raiz. Os caminhos relativos de arquivos permitem hospedagem em subdiretório.

## Conteúdo

As imagens horizontal e vertical da hero foram fornecidas pelo cliente e preparadas em WebP com versões responsivas. A composição horizontal é usada acima de 760px; a vertical, no celular.

Fotografias, símbolo, formação, contatos e trechos de depoimentos têm como fonte o [site da médica](https://drarenatafortunato.com.br/). Os depoimentos são uma seleção pontual, sem sincronização automática. Não foram acrescentadas notas, estatísticas ou avaliações fictícias.

O endereço e o registro profissional foram conferidos também no [perfil público da médica](https://www.doctoralia.com.br/renata-fortunato-da-silva/endocrinologista-medico-clinico-geral/tubarao). As áreas da especialidade seguem a [SBEM](https://www.endocrino.org.br/2008/03/14/endocrinologistas-conheca-o-que-eles-podem-fazer-por-sua-saude/).

Google Maps, WhatsApp e a agenda externa dependem de internet. Não há coleta local de dados de pacientes.

## Interface

- Menu responsivo com fechamento por Escape e seleção de seção.
- Sanfonas independentes com um item aberto por grupo.
- Carrossel de relatos com botões, teclado e rolagem horizontal.
- Preferência de movimento reduzido respeitada.
- Ícones Lucide; tipografia Manrope e DM Sans.

Fotografias e identidade visual permanecem vinculadas à respectiva titular.
